Este proyecto implementa un sistema de control PWM en un ESP32 utilizando FreeRTOS, el periférico LEDC y un protocolo UART personalizado. El objetivo es controlar en tiempo real tres canales PWM independientes mediante comandos enviados desde un script en Python, permitiendo modificar el duty cycle en valores individuales o en listas que se reproducen de manera secuencial y cíclica. Cada canal puede recibir una lista de valores como "SET CH1 20,50,80" y la salida repetirá indefinidamente: 20%, 50%, 80%, 20%, 50%, 80%, con un intervalo de un segundo entre cada cambio, hasta que se reciba una nueva lista. Esta funcionalidad permite observar los cambios tanto en LEDs como en un osciloscopio.

El sistema funciona con cinco tareas FreeRTOS: una tarea UART encargada de recibir los comandos, tres tareas PWM (una por cada canal CH1, CH2 y CH3), y la función principal que inicializa el sistema, colas y periféricos. La comunicación entre UART y los canales PWM se realiza mediante colas FreeRTOS, lo que asegura un intercambio de información estable y sin bloqueos. Cada canal mantiene internamente una lista de valores (hasta 32 elementos) que se cicla indefinidamente. Cuando el usuario envía un nuevo comando SET, el parser reemplaza la lista anterior por la nueva, reinicia el índice de reproducción y notifica a la tarea correspondiente mediante su cola.

El protocolo UART es sencillo y robusto. El formato de comando es: "SET CHx valor1[,valor2,valor3,...]". Se aceptan valores desde 0 hasta 100 como porcentaje del duty cycle. El parser valida la palabra SET, verifica que el canal sea CH1, CH2 o CH3, y separa los valores por comas. Cada valor se convierte a entero, se valida su rango y se guarda en la secuencia asociada al canal. Después de cargar completamente la lista, se envía una señal a la cola del canal para indicarle que debe reiniciar su ciclo de reproducción.

La configuración PWM utiliza el periférico LEDC del ESP32 en modo de alta velocidad, empleando un timer de 13 bits y una frecuencia de 5 kHz. Los pines asignados son GPIO 12 para CH1, GPIO 13 para CH2 y GPIO 14 para CH3. La conversión de duty cycle en porcentaje hacia el registro hardware se realiza con la fórmula: duty_counts = (duty_percent * 8192) / 100, ya que con 13 bits el valor máximo es 8191.

Las tareas PWM operan en un ciclo continuo. Primero consultan si llegó una señal desde el parser indicando nueva lista, y en ese caso reinician su índice a cero. Luego recorren la lista interna cambiando el duty cycle cada segundo. Si la lista está vacía, simplemente esperan. Este diseño garantiza que el sistema siempre esté listo para recibir nuevas órdenes sin bloquearse.

Se incluyen dos scripts Python. El primero, python_test.py, permite enviar comandos automáticos para pruebas rápidas de funcionamiento. El segundo, python_app.py, presenta un menú interactivo donde el usuario puede elegir el canal (CH1, CH2 o CH3), ingresar un solo valor o una lista separada por comas, y enviar el comando SET al ESP32. El script valida que solo se ingresen números y comas antes de enviar la instrucción por puerto serial USB.

Para compilar y cargar el firmware, se utiliza ESP-IDF con los comandos: "idf.py build", "idf.py flash" y "idf.py monitor". Una vez conectado el ESP32 por USB y ejecutado el monitor, se puede controlar el sistema desde Python enviando comandos para cambiar el comportamiento de cada canal. Ejemplos de uso desde Python: "SET CH1 50" fija CH1 en 50%; "SET CH2 10,40,70" hace que CH2 cicle 10%, 40%, 70% indefinidamente.

El sistema cumple completamente los requisitos del proyecto: implementación de tres canales PWM usando LEDC, tareas independientes mediante FreeRTOS, comunicación UART, procesamiento de múltiples duty cycles en secuencia, visibilidad clara de cada valor por un intervalo definido, integración con scripts Python y estructura clara modular. El diseño es estable, no se bloquea, utiliza colas, separa responsabilidades entre UART y PWM, y permite verificar el comportamiento en LEDs o en un osciloscopio.
